# YOLOv8 → YOLO26 WL 推理代码改动说明

## 概述

将 `3_deploy/WL/src` 下的 YOLOv8 推理代码修改为 YOLO26 推理代码，前后处理参考 `3_deploy/src` 下的 YOLO26 参考实现。核心区别在于 **YOLO26 无需 DFL（Distribution Focal Loss）解码，直接输出 ltrb 四个坐标值**，而 YOLOv8 需要 64 通道 DFL 解码。

## 新增文件

### 1. `WL/src/yolo26n.cpp`

基于 `yolov8n.cpp` 修改，主要变更：

| 项目 | YOLOv8 (原) | YOLO26 (新) |
|------|------------|------------|
| 引用头文件 | `#include "postprocess_yolov8.hpp"` | `#include "postprocess_yolo26.hpp"` |
| `bbox_info_channel` | `64` | `4` |

保留 WL170 后端特有逻辑（`icraftRun`、`iclusterId`、`ocmOption`），不做修改。

### 2. `WL/src/yolo26_utils.hpp`

与 `yolov8_utils.hpp` 内容一致，仅文件名更改为 `yolo26_utils.hpp`。包含：
- `_getReal_out_channles(...)` — 根据 bit 位宽计算对齐后的输出通道数
- `set_norm_by_head(...)` — 将 1 维 norm 按 head 数分组

### 3. `WL/src/postprocess_yolo26.hpp`

基于 `postprocess_yolov8.hpp` 修改，核心差异如下：

#### (1) `post_process` — 硬模式 bbox 解码

```cpp
// YOLOv8: DFL 解码（64通道）
std::vector<float> ltrb = dfl(tensor_data, norm[1], obj_ptr_start + real_out_channles[0], bbox_info_channel);

// YOLO26: 直接读取 4 值并乘以 norm
int startptr = obj_ptr_start + real_out_channles[0];
std::vector<float> ltrb = {tensor_data[startptr+0]*norm[1], tensor_data[startptr+1]*norm[1],
                           tensor_data[startptr+2]*norm[1], tensor_data[startptr+3]*norm[1]};
```

#### (2) `post_detpost_soft` — 软模式 box 指针步长

```cpp
// YOLOv8: stride = 64（DFL 通道数）
auto boxPtr = tensor_data_box + h * _W * 64 + w * 64;

// YOLO26: stride = 4（直接 ltrb）
auto boxPtr = tensor_data_box + h * _W * 4 + w * 4;
```

#### (3) `post_detpost_soft` — 软模式 bbox 解码

```cpp
// YOLOv8: DFL 解码
std::vector<float> ltrb = dfl(boxPtr, 1.0, 0, 64);

// YOLO26: 直接读取
std::vector<float> ltrb = {boxPtr[0], boxPtr[1], boxPtr[2], boxPtr[3]};
```

## 修改文件

### 4. `WL/CMakeLists.txt`

```cmake
# 原
set(TARGET_NAME yolov8n)

# 新
set(TARGET_NAME yolo26n)
```

## YOLOv8 vs YOLO26 关键差异总结

| 方面 | YOLOv8 | YOLO26 |
|------|--------|--------|
| Box 编码方式 | DFL（Distribution Focal Loss）64 通道 | 直接 ltrb 回归 4 通道 |
| `bbox_info_channel` | 64 | 4 |
| 硬模式 bbox 解码 | `dfl(tensor_data, norm[1], start, 64)` | 直接读取 `*norm[1]` |
| 软模式 box 步长 | `h * _W * 64 + w * 64` | `h * _W * 4 + w * 4` |
| 软模式 bbox 解码 | `dfl(boxPtr, 1.0, 0, 64)` | `{boxPtr[0..3]}` |

其余逻辑（class score sigmoid、grid 提取、NMS、坐标变换、可视化、时域平滑 `post_detpost_plin`）均保持不变。
