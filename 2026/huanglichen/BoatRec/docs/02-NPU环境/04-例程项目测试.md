## 2 YOLO26 demo 上板

### 2.1 下载（PC 起 http server）

PC 侧（Windows，temp 目录已含 `yolo26_demo.tar.gz` 19MB）：
```
py -3.12 -m http.server 8000 --bind 169.254.135.10 --directory C:\Users\26642\AppData\Local\Temp\opencode
```

板上（所有文件统一放 `/root/boatdet/`）：
```sh
rm -rf /root/yolo26_demo /root/yolo26_demo.tar.gz   # 清理旧残留
mkdir -p /root/boatdet
cd /root/boatdet
python3 -c "import urllib.request; urllib.request.urlretrieve('http://169.254.135.10:8000/yolo26_demo.tar.gz','/root/boatdet/yolo26_demo.tar.gz')"
tar xzf yolo26_demo.tar.gz
rm -f yolo26_demo.tar.gz
```

### 2.2 运行

```sh
cd /root/boatdet/yolo26_demo
python3 run_yolo26.py cfg/yolo26_board.yaml
```

`run_yolo26.py`（板载 buyi）：
- 加载 `imodel/yolo26_0715_BY.json/raw`（13 类，YOLO26 无 DFL，box 4 通道）
- `loadNetwork` → `openDevice("buyi", axi://ql100aiu)` → `initSession` → `session.forward`
- 打印 INPUT/OUTPUT_SHAPE、DetPost_on、各图输出 shape / numpy min-max

> 板上项目统一放 `/root/boatdet/`，上传文件不得存在于其它目录。

## 3 后处理说明（YOLO26）

- YOLO26 **无 DFL 解码**，box 头直接输出 ltrb 4 值（YOLOv8 需 64 通道 DFL）
- 硬模式 bbox：直接读取 4 值 × norm；软模式：`h*_W*4 + w*4`
- 后处理参考：`boatdet/yolo26_demo_cpp/src/postprocess_yolo26.hpp`、`yolo26_demo_cpp/WL/阅读说明.md`（YOLOv8→YOLO26 对照表）
- python 移植后处理（soft：sigmoid + 阈值 + NMS + 坐标变换）后续补
