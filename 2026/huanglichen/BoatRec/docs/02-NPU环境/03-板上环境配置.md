# 03 板上环境配置

> 璞致板 ubuntu rootfs（ImageUSB 镜像烧写）上电后的环境配置：网络持久化、icraft 环境确认、YOLO26 demo 上板运行。

## 1 网络持久化

板子用点对点网线连 PC，eth0 需静态 IP（`169.254.135.20/24`，PC 网口 `169.254.135.10`）。

### 1.1 临时网络（立即生效）

```sh
ifconfig eth0 up
ifconfig eth0 169.254.135.20 netmask 255.255.255.0
ping -c 2 169.254.135.10
```

### 1.2 持久化（重启生效，实测可行）

rootfs 为裁剪版 ubuntu：**无 netplan 命令**、网络由 `networking.service`(ifupdown) + `rc.local` 管理。需同时改两处：

**(a) `/etc/network/interfaces.d/eth0` = static**（原为 dhcp，source-directory 会覆盖主文件）

```
auto eth0
iface eth0 inet static
    address 169.254.135.20
    netmask 255.255.255.0
```

**(b) `/etc/rc.local` 去掉 DHCP**：原有一行 `timeout 5 dhclient`（点对点无 DHCP 服务器→重启后无 IP），替换为静态 IP 设置：

```sh
sed -i 's/timeout 5 dhclient/ifconfig eth0 169.254.135.20 netmask 255.255.255.0/' /etc/rc.local
grep -n "169.254\|dhclient" /etc/rc.local   # 应只剩 169.254 静态设置，无 dhclient
```

**(c) 重启验证**：

```sh
reboot
ip addr show eth0      # 应自动为 169.254.135.20/24
ping -c 2 169.254.135.10
```

> 说明：`ifdown/ifup` 会报 `RTNETLINK File exists`（接口已被手动配置，不影响）；`/etc/netplan/` 里的 config.yaml（dhcp4）因未装 netplan 工具不生效，可忽略。

## 3 python 库安装（离线）

板上 python3.8 为裁剪环境，缺推理所需库；点对点无外网，用 **aarch64 wheel 离线安装**。

### 3.1 已装库清单（离线 wheel，均 `--no-deps` 安装）

| 库 | 版本 | 说明 |
|---|---|---|
| PyYAML | 6.0.3 | 读 yaml 配置 |
| pandas | 1.3.5 | + python-dateutil/pytz/six |
| matplotlib | 3.7.5 | + contourpy/cycler/fonttools/kiwisolver/packaging/pillow/pyparsing |
| importlib_resources | 6.4.5 | matplotlib 在 py3.8 的依赖 |

> 已有：numpy 1.23.0、opencv 4.6.0、icraft 3.31.0。

### 3.2 PC 下载 wheel（x86_64 Windows，http 目录）

```bat
py -3.12 -m pip download <pkg> --platform manylinux2014_aarch64 --python-version 38 --only-binary=:all: -d C:\Users\26642\AppData\Local\Temp\opencode
```
- 纯 python 包（PyYAML/dateutil/pytz/six/cycler/…）用 `--python-version 38 --only-binary=:all:` 即可
- wheel 已缓存在 http 目录，直接 `python -m http.server 8000 --bind 169.254.135.10 --directory <目录>` 提供

### 3.3 板上安装

```sh
cd /root/boatdet
pip3 install --no-deps --no-index --trusted-host 169.254.135.10 --find-links http://169.254.135.10:8000/ \
    pyyaml pandas python-dateutil pytz six \
    matplotlib contourpy cycler fonttools kiwisolver packaging pillow pyparsing \
    importlib_resources
```
> `--no-deps` 避免覆盖已装 numpy 1.23.0（目录内另有 numpy 1.24.4 wheel）。wheel 文件名需保留原格式（不能随意改名，否则 pip 报 invalid wheel filename）。

### 3.4 验证

```sh
python3 -c "import yaml,pandas,matplotlib,importlib_resources; print('deps ok')"
```
