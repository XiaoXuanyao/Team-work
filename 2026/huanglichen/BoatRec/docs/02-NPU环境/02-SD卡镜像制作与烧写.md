# 02 SD 卡镜像制作与烧写（ImageUSB 整卡方案）

## 1 思路

**不重建 rootfs**：直接复用官方 ubuntu icraft 完整镜像（`wk_icraft3.31_unbuntu_sd_Image.bin`，29.7GB），只做两件事：

1. **p1（FAT）换 BOOT.bin** 为璞致板 UART MIO46/47 版本
2. **缩容**到 p1 512MB + p2 9.5GB 的 ImageUSB 整卡镜像

保留官方配套的 Image / fmqlmp-verify.dtb / ubuntu rootfs / 内核模块，**vermagic 天然匹配**（官方内核 Image vermagic = `5.4.52`，rootfs 模块集 `usr/lib/modules/5.4.52/` 配套）。

## 2 关键确认

| 项目 | 结论 |
|---|---|
| 官方 BOOT.bin（18MB） | **不含位流**（无 Xilinx 文本 header、无 sync 0xAA995566）；18MB 是 FSBL+bl31+u-boot+对齐填充 |
| 位流存放 | **独立 `download.bit` 文件**，由 uEnv `fpga loadb` 加载（官方镜像内未放该文件，需自备） |
| 官方 p1（FAT16 1GB） | `BOOT.bin / FSBL.out / Image / fmqlmp-verify.dtb / u-boot / uEnv.txt` |
| 官方 p2（ext4） | 文件系统 **9.5GB**（2490368 块 × 4096），内容 7.7GB；uEnv `root=/dev/mmcblk0p2` |
| 官方 p1 Image | `Linux version 5.4.52-fmsh-sdk-v2024.02`，vermagic **5.4.52** |
| ImageUSB 头格式 | `imageUSB`(UTF16LE)@0x00 + Ver=1@0x20 + Format=3@0x24 + total sectors@0x28 + data_size(QWORD)@0x30 + **MD5**(大写 hex, UTF16LE)@0x40 + Label@0x80；磁盘数据从偏移 512 起 |
| MD5 计算范围 | 跳过 512B 头后的全部磁盘数据 |

## 3 制作流程（WSL Ubuntu-24.04）

工具：`temp/make_pz_image.py`（ImageUSB 头 + MBR + 分区流式复制，已验证）

1. **p1 内容**（`/workspace/sd_image/fat/`，5 文件）：
   - `BOOT.bin`：璞致板 MIO46/47（ql100tai_pz，MD5 `aa2883...`）
   - `Image`：官方 p1 的（vermagic 5.4.52）
   - `fmqlmp-verify.dtb`：官方（含 udmabuf0 128MB）
   - `download.bit`：custop2 位流 `ai7100_top_disable_icap.bit`（17.4MB）
   - `uEnv.txt`：`loadbit` 从 0:1 加载位流 + `root=/dev/mmcblk0p2`

2. **p2**：从官方镜像 p2（文件偏移 `512 + 2101248*512`）流式复制 9.5GB 原样保留（无需解压/重建）

3. **布局**（make_pz_image.py 组装）：
   ```
   [ImageUSB头 512B][MBR 512B][pad→LBA2048][p1 FAT32 512MB @LBA2048][p2 ext4 9.5GB @LBA1050624]
   ```
   - MBR：p1 type 0x0C、p2 type 0x83、0x55AA 签名
   - FAT BPB `hidden_sectors` 修正 = 2048（否则 Windows 不识别）
   - 头 MD5 流式计算覆盖数据区

4. **运行**：`wsl -d Ubuntu-24.04 -u root -- python3 temp/make_pz_image.py`
   - WSL 需先装：`apt-get install -y dosfstools mtools`
   - 输出 `/workspace/sd_image/pz_icraft.bin`（10.74GB，~86s）

## 4 产物与烧写

- 镜像：`data/image/pz_icraft.bin`（10.74GB）
- 烧写：管理员运行 `data/imageUSB.exe` → 选目标 SD 卡 → **Write image to USB drive** → 选 pz_icraft.bin → Write
- 分区：p1 FAT32 512MB + p2 ext4 9.5GB（SD 卡 ≥10GB）
