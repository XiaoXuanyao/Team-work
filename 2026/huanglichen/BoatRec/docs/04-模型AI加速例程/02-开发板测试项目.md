# 02 开发板测试项目

> 璞致板 NPU 推理测试项目：本机开发（`boatdet/yolo26_demo`）+ 板上运行（`/root/boatdet/boatdet`）。
> 用 icraft（buyi 后端）跑 YOLO26 检测，覆盖模型部署、配置、推理与结果查看。

## 1 项目开发环境（本机）

### 1.1 目录：`boatdet/yolo26_demo`

| 路径 | 说明 |
|---|---|
| `run_yolo26.py` | 板载推理主脚本：加载模型 → forward → 解码 → NMS → 画框 |
| `cfg/yolo26_board.yaml` | 推理配置（imodel / dataset / param） |
| `imodel/` | 部署模型 `*_BY.json`（图）+ `*_BY.raw`（权重） |
| `names/yolo26.names` | 类别名（每行一类，13 类） |
| `io/input/` | 测试图片 |
| `io/output/visual/` | 检测结果图 `res_*.jpg` |
| `pyrtutils/` | icraft 运行时库（getJrPath / loadNetwork / initSession / forward 封装） |

### 1.2 关键文件

- **`run_yolo26.py`**
  - `HEAD_SCALES = [(80,8),(40,16),(20,32)]`：3 检测头，stride 8/16/32
  - `decode()`：输出 6 张量（3 尺度 × {cls, box} 交替），cls 经 sigmoid、box 为 ltrb 偏移
  - `letterbox_inverse()`：640×640 左上对齐 letterbox 的框映射回原图
  - 软件 NMS（`cv2.dnn.NMSBoxes`，`fpga_nms=false`）
  - 用法：`python3 run_yolo26.py [cfg.yaml]`（默认 `cfg/yolo26_board.yaml`）

- **`cfg/yolo26_board.yaml`**（要点）
  ```yaml
  imodel:
    mmuMode: true        # MMU 使能（custop2 位流）
    speedmode: true
    compressFtmp: true
    dir: imodel          # 模型目录
    stage: g             # generate 产物
    run_backend: buyi    # NPU 后端
  param:
    conf: 0.25
    iou_thresh: 0.45
    fpga_nms: false      # 软件 NMS
    number_of_class: 13
    number_of_head: 3
  ```

### 1.3 模型
- `yolo26_0715_BY.json/.raw`：早期自训练（13 类）+ icraft 编译（`getJrPath` 自动扫描 `imodel/` 下任意 `*_BY.json`）
- `yolo26m_BY.json/.raw`：后续自训练（13 类），由 `boatdet/modelconverter` 编译，位于 `modelconverter/output/yolo26m/`
- `chusai` 系列（13 类船舶，yolo26s）：`chusai_detpost`（直接训练，旧定稿）、
  **`chusai_finetune2`（MuSGD 微调，新定稿 0.619/20.9ms，无 mix 编译）**；
  评估脚本 `board/eval.py --model <name>`（见 `00-例程/05-微调与量化实验.md`）
- ⚠️ 编译纪律：quantize **禁用 `--mix_precision auto`**（与 DetPost 不兼容，见 `03-ImageMake数据链路优化.md` §4）

## 3 运行测试方法

### 3.1 同步项目到板

```bash
# 本机（PC）打包项目目录
# 用 scp（若已配 SSH）或经 HTTP server（PC 起 http.server 服务 boatdet/）
# 板上拉取：
curl -o /root/boatdet/boatdet -L http://169.254.135.10:8000/<项目包>
# 或直接在板上拉取模型文件到 imodel/：
mkdir -p /root/boatdet/boatdet/yolo26_demo/imodel
curl -o /root/boatdet/boatdet/yolo26_demo/imodel/yolo26m_BY.json \
     http://169.254.135.10:8000/yolo26m/yolo26m_BY.json
curl -o /root/boatdet/boatdet/yolo26_demo/imodel/yolo26m_BY.raw \
     http://169.254.135.10:8000/yolo26m/yolo26m_BY.raw
```

### 3.2 运行推理

```bash
cd /root/boatdet/boatdet/yolo26_demo/board
python3 run_yolo26.py cfg/yolo26_board.yaml
```

- 会打印 `MODEL`、`INPUT_SHAPE`、`OUTPUT_SHAPE`、`DETPOST_ON`、`DEVICE OK`、`SESSION APPLY DONE`
- 每张测试图输出检测结果：类别/置信度/框坐标，并保存 `io/output/visual/res_<图>.jpg`

### 3.3 查看结果

- 板上：`ls io/output/visual/`，查看 `res_*.jpg`
- 或本机：HTTP server 下拉取结果图查看

### 3.4 预期输出（自训练 yolo26m，13 类）

```
=== bc_1222.jpg ===
  DETECTIONS(N): ...
    <class> 0.9xx  box=(x1,y1)-(x2,y2)
DONE
```

检测框应与 GT 贴合（bc_1222 参考 box=(85,218)-(589,370)）。

## 备注
- 换模型：把 `imodel/` 下的 `*_BY.json/.raw` 替换为新模型即可，`run_yolo26.py` 自动识别
- 换类别：`names/yolo26.names` 每行一类，与模型 `nc` 一致（13）
- 参考：`docs/04-模型AI加速例程/01-Icraft模型转换流程.md`、`boatdet/modelconverter/README.md`
