### 5.1 位流产物

|---|---|
| 位流 | `ai7100_top_puzhi.bit`（16.61MB，SHA256 `62EF40BC...`） |
| 格式 | 标准 Xilinx .bit（Vivado 2018.3 默认，头 `00 09 0F F0`） |

### 5.2 位流格式转换（.bit → 字节交换 .bin）

**为何转换**：FMSH `fpga_manager` **只认字节交换 .bin**（官方位流即此格式）；标准 .bit 加载报
`Invalid bitstream, could not find a sync word. Bitstream must be a byte swapped .bin file`。

| 位流 | 头部 | 是否可加载 |
|---|---|---|
| 标准 Xilinx .bit | `00 09 0F F0 ... ai7100_top;UserID=...` | ✗ 需转换 |
| 字节交换 .bin（目标） | sync word + `48 53 4D 46`（ASCII `HSMF`） | ✓ |

**方法 A：Vivado `write_cfgmem`**
```tcl
write_cfgmem -format bin -interface bpix8 \
  -loadbit "up 0x0 D:/HLCH/Works/BoatRec/ai7100_top_puzhi.bit" \
  -file D:/HLCH/Works/BoatRec/ai7100_top_puzhi_swap.bin
```

**方法 B：python 每 4 字节反转**（解析 .bit ASCII 头，对配置数据做 word 内字节反序）
```python
import sys
src, dst = sys.argv[1], sys.argv[2]
data = open(src, 'rb').read()
i = 13  # 跳过 .bit 固定头(0x00,0x09 + padding)
# 解析 'a'/'b'/'c' 字段，定位 'd'(0x64) 数据流起始
while i < len(data):
    tag = data[i]
    if tag == 0x64:                       # 'd': 配置数据(4字节长)
        ln = int.from_bytes(data[i+1:i+5], 'big'); i += 5 + ln; break
    elif tag in (0x61, 0x62, 0x63):       # 'a'/'b'/'c': 字符串字段(2字节长)
        ln = int.from_bytes(data[i+1:i+3], 'big'); i += 3 + ln
    else:
        i += 1
payload = data[i:]                        # 从 sync word(AA 99 55 66) 开始
out = bytearray(len(payload))
for j in range(0, len(payload) - 3, 4):   # 每 4 字节反转（word 内字节反序）
    out[j:j+4] = payload[j:j+4][::-1]
open(dst, 'wb').write(out)
```
运行：`python swap_bit.py ai7100_top_puzhi.bit ai7100_top_puzhi_swap.bin`

**核对**：转换后头部应为官方字节交换格式（sync word + `HSMF` 标志），能正常加载且不再报 sync word 错误。
