# 03 SD卡烧写

## 1 SD卡结构

最小 Linux 启动采用 **单 FAT32 分区**（ramdisk 方案）：

| 分区 | 格式 | 容量 | 内容 |
|---|---|---|---|
| 1 | FAT32 | ≥512MB | 启动文件 + initrd |

备选（后续 M3 需要完整 rootfs，如 Ubuntu + icraft 运行时）：

| 分区 | 格式 | 容量 | 内容 |
|---|---|---|---|
| 1 | FAT32 | 512MB~1GB | 启动文件 |
| 2 | EXT4 | ≥8GB | rootfs |

## 2 镜像提取

### 2.1 100T 研发板 prebuilt 20250408（当前方案）

从 **100T 研发板 prebuilt 20250408** 提取启动文件（下载站缓存 `08_PSOC/.../03_linux_Prebuilt_Image/20250408/`），复制到 `data/sd/fmsh_official_ramrootfs_boot/`：

- `bl31.elf`、`u-boot.elf`（BOOT.bin 分区用）
- `Image`（Linux 内核 5.4.52）
- `system-top.dtb`（设备树）
- `u-rootfs`（initrd，mini rootfs）
- `rootfs.cpio.gz` / `rootfs.tar.bz2` / `image.ub`（备用）

`BOOT.bin` 为自制（见 `02-启动文件制作.md`）。

### 2.2 复旦微示例 ImageUSB 整卡镜像（参考）

复旦微提供悟空板 Ubuntu 整卡镜像（ImageUSB 格式），可一键烧写 SD 卡：

- 镜像：`04_FPAI/02_Icraft/v3.31/系统生态/Linux/ubuntu20.4/ubuntu镜像文件/wk_icraft3.31_unbuntu_sd_Image.bin`（≈29.7GB，由同目录 `.rar` 解压）
- 格式：ImageUSB = **512 字节文件头 + 整盘磁盘原始数据**（第三方工具读取需跳过前 512 字节）
- 分区结构：

| 分区 | 类型 | 起始 LBA | 大小 | 内容 |
|---|---|---|---|---|
| 1 | FAT16/LBA（0x0E） | 2048 | 1GB | BOOT：BOOT.bin / Image / dtb / uEnv.txt 等 |
| 2 | Linux/ext4（0x83） | 2101248 | 26.1GB | Ubuntu 20.4 rootfs（含 icraft3.31 运行时） |

- 烧写：`imageUSB.exe` 一键写入（自动处理 512B 头）

> 该镜像为悟空板（复旦微官方 100T 开发板）示例，其 FSBL/BOOT.bin 与璞致板不兼容（DDR 布局差异，调试记录已确认启动无输出），仅作**分区结构与 rootfs 参考**。

## 3 FAT 与 EXT4 分区内容

**FAT32 分区**（根目录，当前版 6 个文件）：

| 文件 | 说明 |
|---|---|
| `BOOT.bin` | 自制启动镜像（FSBL+bl31+u-boot） |
| `Image` | Linux 内核 |
| `system-top.dtb` | 设备树 |
| `u-rootfs` | initrd（mini rootfs） |
| `uEnv.txt` | 启动脚本（booti 加载 Image+dtb+initrd） |
| `download.bit` | M2 AI 位流（custop2，`ai7100_top_disable_icap.bit`） |

> 版本目录：`data/sd/2026-08-11_1938_MIO46-47_ql100tai_pz/`（当前）；`bl31.elf`/`u-boot.elf` 素材在 `data/sd/fmsh_official_ramrootfs_boot/`。

**EXT4 分区**（备选，rootfs 方案）：解压 rootfs 到分区根目录，例如 Ubuntu rootfs：

```bash
sudo mkfs.ext4 /dev/sdX2
sudo mount /dev/sdX2 /mnt
sudo tar -xpf icraft3.31_ubuntuFs.cpio.gz -C /mnt   # 或 cpio -idmv
sudo umount /mnt
```

同时需将 `uEnv.txt` 的 `bootargs` 中 `root=/dev/ram` 改为 `root=/dev/mmcblk0p2 rootwait rw`，并把 FAT 分区中 `u-rootfs` 移除（改用 EXT4 的 rootfs）。
