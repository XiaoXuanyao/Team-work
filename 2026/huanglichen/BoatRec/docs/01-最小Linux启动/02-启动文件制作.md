# 02 启动文件制作

## 1 BOOT.bin

BOOT.bin 由 **FSBL.out、bl31.elf、u-boot.elf** 组成（参照 `output.bif`：`[bootloader]FSBL.out` + `[destination_cpu=apu_0]bl31.elf` + `u-boot.elf` + `[fsbl_config]apu_x64`）。

### 1.1 FSBL.out

来源：Procise 工程导出的 FSBL 工程，经 IAR 编译
方法：见 `01-Procise项目.md` 第 4 节（proj260811 从零）或第 5 节支路（悟空板工程，推荐），产物分别为：
- `procise/proj260811/SDK/design_1_platform/FSBL/Debug/Exe/FSBL.out`
- `procise/ql100tai_pz/SDK/ql100tai_platform/FSBL/Debug/Exe/FSBL.out`（UART0=MIO46/47）

> 两条路线均需保证 UART0 = MIO46..47（璞致板实际接线）。

### 1.2 bl31.elf

来源：100T 研发板 prebuilt 20250408（同芯片 JFMQL100TAI900）
方法：直接复用 `data/sd/fmsh_official_ramrootfs_boot/bl31.elf`（串口 uart0 与璞致板一致，无需重编）

### 1.3 u-boot.elf

来源：100T 研发板 prebuilt 20250408（同芯片）
方法：直接复用 `data/sd/fmsh_official_ramrootfs_boot/u-boot.elf`（已适配 100TAI 标准外设，MIO 由 FSBL 配置）

### 1.4 Create Boot Image

在 Procise 中打开启动镜像制作（`PSOC → Create Boot Image`）：

1. `Output BIF file path` 设为 `procise/proj260811/bootgen/output.bif`（或支路 `procise/ql100tai_pz/ql100tai_pz_boot.bif`）；`Output path` 设为对应目录 `BOOT.bin`
2. 在 `Boot image partitions` 区域依次 `Add` 三个分区（需严格按照下面顺序放置）：

   | 文件 | 导出路径（相对） | Partition type | 其他配置 |
   |---|---|---|---|
   | FSBL.out | `procise/proj260811/SDK/design_1_platform/FSBL/Debug/Exe/FSBL.out` | bootloader | Destination CPU 默认 APU×64（无需改） |
   | bl31.elf | `data/sd/fmsh_official_ramrootfs_boot/bl31.elf` | datafile | Destination CPU = apu_0 |
   | u-boot.elf | `data/sd/fmsh_official_ramrootfs_boot/u-boot.elf` | datafile | Destination CPU = apu_0 |

   - Partition type 三种选项：`bootloader`（FSBL）、`init`（寄存器初始化 .int）、`datafile`（其他类型）；bl31/u-boot 均选 `datafile`
   - Authentication / Encryption 全部选 `none`，无需填 Load/offset（ELF 自带加载地址）

3. 全局 `fsbl_config` 选 `apu_x64`
4. 点击 `Create Image`，输出 `BOOT.bin`（放入 SD 卡 FAT 分区）
