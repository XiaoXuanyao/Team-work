# 01 设备说明

## 1 设备型号

- **DDR3 型号**：MT41K256M16 XX-125
  - 类型：DDR3L（板上 1.8V 电平）
  - 容量：1GB（2 片 4Gb×16bit 拼 32 位总线）
  - 频率：400MHz（Speed Bin DDR3-1600X，CL/CWL=12/8，tRCD/tRP=11/11）
  - PLL：工具自动配置（不勾 Override Clocks；实测 DDR 200MHz，PLL 分频 5）

- **设备 1（主控芯片）**：复旦微 **JFMQL100TAI900**
  - 封装/等级：fcbga900，速度等级 -2，TSMC 28nm HPC+
  - 架构：FMQLMP = PS + PL + 内置 NPU（异构 FPAI）
  - PS：4×Cortex-A53（ARMv8 64 位，默认 1GHz），GIC-400，CCI-500
  - AI：内置 NPU 硬核（寄存器段 0x40040000~0x4007FFFF）+ NPU DMA（0x80000000）
  - GPU：Mali-Bifrost（0xF0000000）；VPU：视频编解码（0xF0020000）
  - 启动模式：SD / QSPI / NAND / JTAG

- **设备 2（开发板）**：璞致 **PZ7100F-FH-KFB** 平台开发板（核心板 + 底板）

## 2 开发板详细配置

### 2.1 调试与网络接口

| 接口 | 配置 | 说明 |
|---|---|---|
| 调试串口 | UART0，115200 8N1 | `ttyPS0`，0xE0004000，调试记录端口为 COM7 |
| 以太网 | 千兆 RGMII | gmac0，0xE0047000，PHY 复位 IO_L6P_9/Y20，MDC/MDIO MIO52/53 |
| USB | USB0 / USB1（OTG） | 0xE0045000 / 0xE0046000 |

### 2.2 存储接口

| 接口 | 规格 | MIO |
|---|---|---|
| SD 卡 | SD0 卡槽（启动介质，主线用） | — |
| QSPI Flash | 32MB（s25fl256s） | MIO1~6 |
| eMMC | 8GB | MIO10~15 |
| NAND | 预留 | MIO4~13 |

### 2.3 其他板载资源

| 资源 | 说明 |
|---|---|
| CAN | CAN0/CAN1（0xE0005000 / 0xE0006000） |
| I2C | I2C0/I2C1，板载 24C256 EEPROM |
| SPI | SPI0/SPI1（0xE0001000 / 0xE0021000） |
| PCIe | 8 lane，5GT/s（MGT BANK112） |
| LED/按键 | LED×5、按键 |
| 高速 ADC | AD7606 / AD9643 |
| 其他 | LCD、SFP 等 |

### 2.4 电源与结构

- 供电：8~12V / 2A 直流输入
- 核心板 83.8×64.8mm；底板 220×116mm
