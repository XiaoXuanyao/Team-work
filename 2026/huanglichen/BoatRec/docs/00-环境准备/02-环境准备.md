## 1 软件环境 - Procise+IAR

**用途**：FPGA 工程（块设计/PS 配置/综合实现/位流）+ 启动文件生成（FSBL/Boot Image）。

| 软件 | 版本 |
|---|---|
| Procise | 2025.1.1（build 31969）+ patch V2.1 |
| IAR Embedded Workbench for ARM | 9.20.4（iccarm 9.20.4.327） |

### 1.1 Procise 安装方法

**安装包**（本地已缓存）：

| 包 | 位置 |
|---|---|
| 基本包 + V2.1 patch（全新安装） | `13_PROCISE软件/release最新版本/04_FMSH_Procise_2025.1.1_202511201452_31969_基本包_加独立V2.1_patch包（全新安装只需下载该压缩包）.rar`（871MB） |

**系统要求**：Windows 7 SP1 ~ Windows 11（64 位）；内存 ≥4G；存储 ≥64G；**安装路径必须全英文**；安装时建议退出安全软件（360/金山等可能致安装失败）。

**安装步骤**：

1. 解压基本包 rar，运行安装程序
2. `Next` → 选择安装目录（全英文，如 `C:\Program Files (x86)\Procise`）→ `Next`
3. 确认安装组件 → `Next` → `Install`
4. 安装完成后自动安装 Jlink/Digilent 驱动 → `Finish`
5. 若为旧版升级：另运行 V2.1 独立 patch 安装包
6. **License**：Procise 安装包自带通用 license；特殊功能需将 license 文件放入 `安装目录\data`
7. **验证**：启动 Procise，About 界面显示 `2025.1.1 build 31969`

**常见问题**：

- 启动闪退/无反应：删 `C:\Users\<用户名>\AppData\Roaming\FMSH` 后重试
- 报 `No License`：检查网卡启用、license 文件位置与 MAC 匹配、系统时间

### 1.3 Procise 中设置 IAR

**机制**：Procise 的 PSOC（SDK）功能生成 IAR 工程（`.eww`/`.ewp`）并调用 IAR 编译（如 FSBL.out）。IAR 安装时自动写入注册表，Procise 据此自动识别，**无需手动配置路径**。

**注册表登记项**（IAR 安装时自动生成，供核对）：

| 键 | 值（本机） |
|---|---|
| `HKLM\SOFTWARE\IAR Systems\Embedded Workbench\5.0\EWARM\9.20.4` → InstallPath | `C:\Program Files\IAR Systems\Embedded Workbench 9.0` |
| `HKLM\SOFTWARE\IAR Systems\Embedded Workbench\5.0\Locations\Location1` → InstallPath / ExePath | `...\Embedded Workbench 9.0` / `...\common\bin\iaridepm.exe` |

**设置/核对**：

1. 先安装 IAR 9.20.4（见 1.2），安装后注册表自动登记
2. 若 Procise 找不到 IAR：确认版本为 **9.20.4**（非 8.x/9.30），安装完整，然后重启 Procise
3. 本机实测：Procise 导出 SDK 已能生成 `design_1_platform.eww`（内含 FSBL 工程）

**验证**：在 Procise 中打开 SDK 工作区并编译 FSBL 无报错，产物 `FSBL/Debug/Exe/FSBL.out`。

## 2 软件环境 - ImageUSB

**用途**：将整卡镜像（`.bin`，含完整分区布局）一键烧写至 SD 卡/U 盘（M1 烧卡用）。

| 项目 | 值 |
|---|---|
| 工具 | PassMark ImageUSB |
| 位置 | `data/imageUSB.exe` |
| 适用镜像 | 整卡镜像（如 `data/work_image_rebuild/wk_icraft3.31_pz_boot_10G.bin`，悟空缩容版） |

**使用步骤**：

1. 插入 SD 卡（读卡器/板卡 SD 槽），确认系统识别为磁盘
2. 打开 `imageUSB.exe`
3. 勾选目标设备（注意不要选错磁盘）
4. 选择镜像文件（.bin）
5. 点击 `Write Image to Device`，等待完成

**注意**：

- 整卡镜像含分区布局（FAT + ext4），烧录后无需手动分区；非整卡方案（手动 FAT+ext4）用 Windows 磁盘管理或其他分区工具
- 烧录前确认磁盘容量 ≥ 镜像大小
- Linux 下可用 `dd` / SDK `install_to_sd.sh` 替代

## 3 软件环境 - PuTTY

**用途**：串口调试终端（M1 观察启动日志）。SSH 用 Xshell（见第 4 节）。

| 项目 | 值 |
|---|---|
| 工具 | PuTTY |
| 位置 | `C:\Program Files\PuTTY\putty.exe` |
| 串口参数 | COM7，115200，8N1 |

**串口连接配置**：

1. `Session` → `Connection type`：`Serial`
2. `Serial line`：`COM7`；`Speed`：`115200`
3. `Window → Translation`：UTF-8（避免中文乱码）
4. 输入会话名（如 `PZ7100F-COM7`）→ `Save`，之后双击复用
5. `Open` 打开终端，板卡上电后观察 bootrom→FSBL→u-boot→kernel 日志

## 4 软件环境 - Xshell + Xftp

**用途**：Xshell = SSH 登录板卡 Linux；Xftp = 板卡与上位机之间文件传输（M2/M3 传运行库、模型、程序）。

| 项目 | 值 |
|---|---|
| Xshell | 8，`C:\Program Files (x86)\NetSarang\Xshell 8\Xshell.exe` |
| Xftp | 8，`C:\Program Files (x86)\NetSarang\Xftp 8\Xftp.exe` |
| 登录 | root / fmsh（板卡 IP 由 u-boot/网络配置确定） |

**Xshell SSH 连接**：

1. `文件` → `新建`
2. `主机`：板卡 IP（如 192.168.x.x）；`协议`：SSH；`端口`：22
3. 会话命名（如 `PZ7100F-SSH`）→ 保存
4. 连接后登录 `root` / `fmsh`

**Xftp 文件传输**：

1. 打开 Xftp（可在 Xshell 会话内按快捷键或直接新建会话）
2. `新建` 会话，主机为板卡 IP，SSH/SFTP，端口 22，登录 root/fmsh
3. 左侧本地目录，右侧板卡目录（如 `/home/fmsh/`），拖拽即可上传/下载
4. 注意：上传的可执行文件需 `chmod +x`
